# 项目文档

本目录与 `Assets/` 平级，存放**项目规范文档**。因为不在 `Assets/` 下，Unity 不会导入它，
也不会被 AssetsBundle / 出包流程带上。

## 索引

| 文档 | 用途 |
|---|---|
| [Skills/出包与发布流程.md](Skills/出包与发布流程.md) | 出包、发布到腾讯云、验收、回滚的标准流程（人和 AI 都按它执行） |
| [AB包管理器.md](AB包管理器.md) | AB 包加载器的核心机制：异步加载、缓存、引用计数、依赖管理、去重、失败处理 |

## 约定

- 出包/发布相关的流程改动，先改这里的文档，再改脚本（`Tools/deploy/`），保持两边一致
- 文档里出现的路径、IP、账号必须与当前实际环境一致；换了服务器要同步更新

## 常用入口

- **出包 / 切地址**：Unity 菜单 **Tools → FPSGame-Y1**（面板快捷键 **Ctrl+Shift+B**）
  客户端打包 / 服务端打包 / 双端同时出包 / 切换本地·真实服地址 —— 详见
  [Skills/出包与发布流程.md](Skills/出包与发布流程.md) 第 2 节
- **发布到腾讯云**：`Tools/deploy/deploy.ps1`（输出目录由上面的面板固定为 `Build\LinuxServer`）
